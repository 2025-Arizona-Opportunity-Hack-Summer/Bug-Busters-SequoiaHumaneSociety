    #Problem Statement

    Animal shelters often receive pets without names or with names that need changing. While naming may seem simple, it plays a critical role in a pet’s identity, adoptability, and emotional connection with potential adopters. At the same time, shelters like Sequoia Humane Society continuously face funding challenges to support animal care, medical treatments, and daily operations.
    To address both needs, "Name a Shelter Pet" was created — a digital platform that allows community members to submit name suggestions for rescue animals in exchange for a donation. The system streamlines the naming process, sends donor confirmation emails, and fosters a meaningful bond between supporters and pets. This not only enhances the visibility and personality of animals but also helps generate vital funds and increase community engagement — ultimately supporting higher adoption rates and better care for shelter animals.

    #Tech Stack

    Frontend:
    HTML/CSS - structure and style web interface
    Backend:
    Python 3 - main programming language
    Flask - web framework
    Database:
    SQLite - store pet data, name suggestions, admin requests
    SQLAlchemy - used to interact with database using python
    Email & Payment Services:
    SendGrid - used to send confirmation emaials when name suggestions are submitted and approved.
    Stripe - used to make a donation payment
